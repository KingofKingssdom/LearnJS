# Cú pháp cơ bản Javascript
Các cú pháp cơ bản cần nhớ
## I. Khoảng trắng
Các khoảng trắng giữa các dòng mã trong js nó sẽ được bỏ qua khi công cụ js đóng gói tệp đó thành file để nhẹ hơn. Nên khi viết mã js cứ sử dụng khoảng cách để mã dễ đọc
## II. Tuyên bố
Nghĩa là kết thúc câu lệnh js có thể không cần dấu chấm phẩy. Nhưng khuyên nên dùng
## III. Khối lệnh
Nó được bọc trong dấu đóng mở ngoặc nhọn nó đc gọi là một khối lệnh
## IV. Định danh
Các tên như tên biến, tên class, tên function, các tham số được gọi là định danh
